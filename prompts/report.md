# Report structure — owned by the analytics team with the CEO.

Write in markdown:
- A title.
- One headline sentence containing the key number.
- Findings: 3-5 points, each with its evidence from the data.
- Why: name the driver and say how confident you are. For a comparison, decompose it —
  revenue per customer = items per customer x average item price; a revenue change is
  customers x orders per customer x basket value. Name which component moved.
- ACTION ITEMS: numbered, concrete, owned where possible, with a date where it makes sense.

Every number must appear in the data provided, **as a value in the rows** — do not compute one.

That means no totals, averages, differences or percentages you worked out yourself. If you want a
six-month total per brand, ask for it: the data tool can return the total alongside the monthly
figures in the same query. A number you calculated cannot be traced back to a row, so it cannot be
checked, and the quality gate will reject the report.

Never estimate, recall or illustrate a figure. State the time window the data covers.
